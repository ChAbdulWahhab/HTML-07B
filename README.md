# HTML Fundamentals Practice

This repository contains basic HTML practice files and code examples designed to cover core web development concepts, structural tags, and styling fundamentals.

---

## File Overview

* **01_intro.html**: Basic HTML document structure and introductory tags.
* **02_pre.html**: Usage of preformatted text using the `<pre>` tag.
* **03_formatting.html**: Text formatting elements including bold, italic, and inline styling.
* **04_colors.html**: Applying color properties through CSS and inline attributes.
* **04_images.html**: Embedding and managing image elements (`<img>`).
* **04_links.html**: Hyperlinks navigation and anchor elements (`<a>`).
* **04_quotation.html**: Formatting quotes and citations (`<blockquote>`, `<q>`).
* **04_task.html**: Practical exercise/task combining the covered HTML concepts.
* **images/**: Directory containing image assets used across the HTML files.
